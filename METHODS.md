# Methods & Reproducible Results

This document summarizes the methodology and headline results for the book chapter.
Every number and figure below is regenerated by `make reproduce` (`python -m src.train`
then `python -m src.report`); seeds are fixed at 42.

## 1. Data and preprocessing
- **Primary cohort:** Pima Indians Diabetes Dataset (n=768 adult women, prevalence 34.9%).
- **Cleaning:** physiologically impossible zeros in Glucose, BloodPressure, SkinThickness,
  Insulin, and BMI are recoded as missing and median-imputed (fit on training folds only).
- **Derived features:** clinically motivated interactions/ratios (Glucose×BMI, BMI×Age,
  Insulin/Glucose, etc.).
- **Scaling:** standardized; all steps live inside an sklearn `Pipeline` so no
  preprocessing statistic leaks across the train/test boundary.

## 2. Models and selection
Seven models were compared by **repeated stratified 5-fold CV (3 repeats)** on ROC-AUC:
Logistic Regression, Random Forest, Extra Trees, Gradient Boosting, XGBoost, LightGBM,
and a stacked ensemble (LR meta-learner over the others). **Extra Trees** was selected
(CV ROC-AUC **0.844 ± 0.031**).

### Model comparison (DeLong test vs best)
| Model | CV ROC-AUC | DeLong p vs best |
|---|---|---|
| Extra Trees | 0.844 | — |
| Logistic Regression | 0.843 | 0.90 |
| Stacked Ensemble | 0.842 | 0.51 |
| Random Forest | 0.833 | 0.003 |
| Gradient Boosting | 0.823 | 0.004 |
| XGBoost | 0.818 | 0.0004 |
| LightGBM | 0.813 | 1.5e-05 |

**Honest finding:** the top model is **not statistically distinguishable** from plain
logistic regression (p=0.90). On data this size, a simple, interpretable baseline is
competitive — a result worth stating plainly rather than overclaiming the ensemble.

## 3. Ablation study
| Configuration | CV ROC-AUC |
|---|---|
| Raw features (no cleaning) | 0.836 |
| + zeros-as-missing imputation | 0.843 |
| + derived clinical features | 0.844 |
| Stacked ensemble (full pipeline) | 0.842 |

The zeros-as-missing handling is the single most useful preprocessing step; derived
features add a marginal gain; ensembling does not beat the single best tree model here.

## 4. Held-out performance with 95% bootstrap CIs
On a 20% stratified hold-out, calibrated, at the F1-tuned threshold (≈0.28):

| Metric | Estimate | 95% CI |
|---|---|---|
| ROC-AUC | 0.823 | [0.754, 0.882] |
| PR-AUC | 0.681 | [0.551, 0.803] |
| Brier | 0.166 | [0.133, 0.202] |
| Accuracy | 0.734 | [0.662, 0.799] |
| Precision | 0.584 | [0.474, 0.686] |
| Recall | 0.833 | [0.736, 0.933] |
| F1 | 0.687 | [0.593, 0.770] |

CIs are wide because the test set is small (~154 patients) — quantifying that uncertainty
is the point. See `reports/roc_curves.pdf` (ROC with bootstrap band) and
`reports/calibration.pdf` (reliability diagram; Platt scaling reduces ECE).

## 5. Explainability (SHAP)
Global mean-|SHAP| ranks **Glucose** first, followed by the Glucose×BMI and BMI×Age
interactions and Age — consistent with established clinical risk factors, which validates
the model qualitatively for non-ML readers. See `reports/shap_summary.pdf` and a
per-patient `reports/shap_waterfall.pdf`.

## 6. External validation (Pima → NHANES)
The model was trained on Pima and evaluated, with no refitting, on an independent cohort:
**NHANES 2017–2018 women aged ≥21** (n≈1,181, prevalence 15.7%), using the four shared
measurements (Glucose, BloodPressure, BMI, Age).

| Metric | Internal (Pima hold-out) | External (NHANES) |
|---|---|---|
| ROC-AUC | 0.821 | 0.822 [0.789, 0.854] |
| PR-AUC | 0.686 | 0.540 |
| Accuracy | 0.747 | 0.848 |

**Discrimination (ROC-AUC) transports almost perfectly across cohorts** — a strong result.
PR-AUC drops because NHANES has a much lower base rate (precision-recall is base-rate
sensitive), and accuracy *rises* for the same reason. This is exactly the kind of
base-rate effect the GeoAI prior correction (below) is designed to address.

## 7. GeoAI: geographic prior correction
Personal risk is combined with **CDC PLACES 2024** county prevalence (all 3,144 US
counties; diabetes, obesity, inactivity, blood pressure, insurance access). The calibrated
probability is re-expressed to a county's base rate by an **odds-ratio prior correction**:

> adjusted_odds = model_odds × [ p_county/(1−p_county) ] / [ p_train/(1−p_train) ]

This shifts the base rate while preserving the model's relative ranking. As a sanity check,
applying the correction *at the training prevalence* reproduces the input exactly
(identity-map error ≈1e-16). See `reports/geo_map.pdf` and `reports/geo_prior_correction.pdf`.

**Interpretation and caveat:** the adjustment assumes the discriminative signal transports
across populations (supported by §6's stable ROC-AUC) while base rates differ by place. It
re-expresses *population* risk context, not place-based biology, and is not a diagnosis.
